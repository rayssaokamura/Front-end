

### Sobre o Projeto

Aplicação web desenvolvida para o primeiro projeto da disciplina de Programação Web Fullstack, utilizando React.js para consumir e apresentar dados da Sakura Card Captor API.

O projeto segue o conceito de SPA (Single Page Application), permitindo a interação com os dados sem redirecionamento entre páginas.

### Tecnologias

- React.js
- JavaScript
- AJAX

### API

[Sakura Card Captor API](https://github.com/JessVel/sakura-card-captor-api)

A API fornece informações sobre as cartas de *Cardcaptor Sakura*, incluindo seus nomes, características e imagens.
